## 🛠️ Meus projetos

### ⚡ Fonte de bancada utilizando fonte ATX

Construí uma fonte de alimentação de bancada reaproveitando uma fonte ATX de computador.

O projeto permitiu aplicar conhecimentos de eletrônica, fontes de alimentação e reutilização de componentes, transformando um equipamento de computador em uma ferramenta para experimentos.

### 🖥️ HOMETECH — Servidor NAS caseiro

Montei um servidor NAS utilizando componentes de um computador antigo.

**Tecnologias utilizadas:**
- TrueNAS
- Nextcloud
- Tailscale
- Redes locais
- Containers

O servidor permite armazenar arquivos em uma nuvem pessoal e acessá-los remotamente.

O projeto também envolve o desenvolvimento de ferramentas próprias para monitoramento do hardware.

### 📟 Monitoramento com ESP32

Projeto de integração de um ESP32 com display touchscreen ao servidor HOMETECH.

O objetivo é visualizar informações sobre discos, temperaturas, CPU, memória RAM e status do servidor, além de estudar possibilidades de automação.

### 📦 Sistema de pedidos e estoque

Projeto de desenvolvimento de um sistema de gerenciamento de pedidos, produtos e estoque.

Estou utilizando esse projeto como oportunidade para aprender e praticar Java, PostgreSQL, HTML, CSS e JavaScript, aplicando conceitos de programação e banco de dados.
