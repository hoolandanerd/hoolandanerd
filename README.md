### 🖥️ HOMETECH — Servidor NAS

Servidor NAS construído com componentes de um computador
antigo, utilizando TrueNAS, Nextcloud e monitoramento
integrado com ESP32.

O gabinete possui cinco baias frontais para discos,
ventilação personalizada e display touchscreen.

<p align="center">
  <img src="./servidor-nas.jpeg" alt="Servidor NAS HOMETECH"
       width="550">
</p>


**Tecnologias utilizadas:**

- TrueNAS
- Nextcloud
- Tailscale
- Redes locais
- Containers
- Python para monitoramento

**Funcionalidades:**

- Armazenamento de arquivos em rede
- Nuvem pessoal
- Sincronização de arquivos e fotos
- Acesso remoto
- Monitoramento de recursos do servidor

### 📟 Monitoramento do servidor com ESP32

Projeto de integração de um ESP32 com display touchscreen ao servidor HOMETECH.

**Recursos implementados e em desenvolvimento:**

- Comunicação com API de monitoramento
- Visualização de discos e suas informações
- Acompanhamento de CPU e memória RAM
- Monitoramento de temperaturas
- Estudos para automação e controle do servidor
